First-time setup
  1. Sign in to GitHub as richardxu257.
  2. Create a fine-grained personal access token with an expiration date you’re comfortable with.
  3. Choose Only select repositories: website-writing-drafts and richardxu257.github.io.
  4. Under Repository permissions, set Contents to Read and write. No other additional permissions are needed.
  5. Generate the token yourself and enter it above. Keep it in your password manager if you want to reuse it; don’t paste it into chat.
